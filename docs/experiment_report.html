FINDINGBehaviour surfaced by the run

The cooling loop ignored the hotter stack. Over the 11.5 s window, Stack 2 rose +4.9 °C (56.9 → 61.8) while the compressor spun down to its 12 000 RPM floor and chiller fluid drifted up. The injector's control rule keys cooling off Stack 1 only (if s1_temp > 65), which stayed ~55 °C — so a Stack-2-only excursion never triggers feed-forward cooling. A useful design flag for the Phase-3 thermal logic: the control input should track the max of both stacks, not just Stack 1.
